1. Computer Hardware, CPU & Memory +

1. The CPU (Central Processing Unit)

The CPU is the brain of the computer. It has two main parts:

  • ALU (Arithmetic Logic Unit): Does all the math (addition, subtraction) and logic (comparing numbers).
  • Control Unit (CU): Directs traffic. It tells the rest of the computer what to do.
  • Internal Bus: The highway that carries data between the CPU parts.

2. The Instruction Cycle

When the CPU runs a program, it follows three steps:

  • Fetch: The CU gets the instruction from RAM.
  • Decode: The CU translates the instruction into signals.
  • Execute: The ALU carries out the math or logic.

3. Memory Types (Crucial for Exams)

  • RAM (Random Access Memory): This is temporary memory. It holds programs that are currently running. It is Volatile, meaning it loses all data when the power goes off. If you increase RAM, your computer runs faster because it can hold more programs at once.
  • ROM (Read Only Memory): This is permanent memory. It holds the BIOS (the instructions needed to boot up the computer). It is Non-volatile.
  • Cache: Super fast memory built directly into the CPU. It stores frequently used data so the CPU doesn't have to wait for RAM.
  • EPROM: A type of ROM that can be erased and reprogrammed using electrical signals.

Exam Tip: If a PC has no RAM, it will not boot. Without RAM, the OS cannot load.

2. Input/Output, Storage & Ergonomics +

1. Data Transfer (DMA)

Direct Memory Access (DMA): This is the fastest way to move large amounts of data. It allows a device (like a hard drive) to send data directly to RAM without bothering the CPU. This frees up the CPU to do other work.

2. Storage Media

  • Magnetic: Hard Disk Drives (HDD) and Floppy Disks. Use magnets to store data.
  • Optical: CDs, DVDs. Use a laser to read data. The data is stored in pits (holes) and lands (flat areas).
  • Solid State: Flash drives, SSDs. No moving parts, very fast.
  • Defragmentation: Over time, files get scattered (fragmented) on a hard drive. Defragmentation rearranges the files so they are stored serially (next to each other), which speeds up read time.

3. Ergonomics & Health

  • RSI (Repetitive Strain Injury): Pain in the wrists/hands from typing too much. Prevented by taking breaks, using wrist rests, and using ergonomic keyboards.
  • Eye Strain: Prevented by using antiglare screens, LCD monitors, and looking away from the screen regularly.
3. Software, OS & Language Translators +

1. Language Translators

Computers only understand Machine Code (1s and 0s). Translators convert human code into machine code.

  • Compiler: Translates the entire program at once. Makes a .exe file.
  • Interpreter: Translates code line by line. Easier to debug.
  • Assembler: Translates low-level Assembly language into machine code.

2. The Operating System (OS)

The OS is the master software (e.g., Windows, Linux, DOS). It manages:

  • Memory Management: Allocates RAM to programs and frees it when they close.
  • File Management: Creates, deletes, and organizes files/folders on the disk.
  • Mono-tasking OS: Can only run ONE program at a time (e.g., DOS).

3. Programming Concepts

  • Iteration: A loop. Repeats a set of instructions.
  • Array: A list of items of the same type. Accessed by an Index (e.g., Array[0]).
  • Variable: A storage location that must be declared before use.
4. Data Representation & Logic Gates +

1. Number Systems

Computers use Binary (Base 2). Humans often use Hexadecimal (Base 16) to shorten binary.

  • Binary to Hex: Group binary bits into 4s. (e.g., 1010 = A, 1111 = F).
  • 8-bit system: Can represent 2^8 = 256 characters (0 to 255).
  • Data Hierarchy: Bit -> Byte -> Field -> Record -> File -> Database.

2. Logic Gates

  • XOR (Exclusive OR): Outputs 1 only if the inputs are DIFFERENT (one 0, one 1). If inputs are the same, it outputs 0.
  • NOR: Outputs 1 only if BOTH inputs are 0.

3. De Morgan's Theorems (For Paper 2)

  • Theorem 1: NOT (A AND B) = (NOT A) OR (NOT B)
  • Theorem 2: NOT (A OR B) = (NOT A) AND (NOT B)
5. Computer Networks +

1. Network Devices

  • Gateway: Connects networks with DIFFERENT protocols. It is a translator.
  • Router: Directs traffic between different networks (like a traffic cop).
  • Switch: Connects devices WITHIN the same network.
  • Bridge: Connects two network segments.

2. Topologies (How cables are arranged)

  • Star: All devices connect to a central hub/switch. If one cable breaks, only that device goes down.
  • Bus: All devices share ONE backbone cable. Uses the least amount of cable.
  • Ring: Devices form a circle.

3. Transmission Types

  • Synchronous: Sends large blocks of data continuously without gaps. Timed by a clock.
  • Asynchronous: Sends data one character at a time with start/stop bits.
  • Serial: Sends bits one after another. Best for long distances.
  • Parallel: Sends multiple bits at once. Fast, but only for short distances.
  • Full-duplex: Both devices can send and receive at the same time (like a phone call).
6. The Internet & Databases +

1. Internet Terms

  • URL: The address of a web page.
  • HTTP: The protocol used to transfer web pages.
  • VoIP: Voice over Internet Protocol (making phone calls over the internet).
  • Telnet: Used to remotely log into another computer.
  • Browser: Software used to view web pages (Chrome, Firefox).

2. Databases

  • Primary Key: A unique identifier for a record (e.g., Student ID).
  • Foreign Key: A field in one table that links to the Primary Key of another table.
  • Normalization: The process of organizing data to reduce redundancy (repetition). If a database is NOT normalized, the same data might appear multiple times.
7. Security, Ethics & SDLC +

1. Malware (Malicious Software)

  • Trojan Horse: Disguises itself as a useful program, but harms the computer when opened.
  • Virus: Attaches itself to a file and spreads.
  • Worm: Spreads itself automatically across networks.
  • DoS (Denial of Service): Floods a website with fake traffic so real users cannot access it.

2. Security & Ethics

  • Data Protection Legislation: The law that protects citizens' personal data.
  • Good Security: Regular off-site backups, strong passwords, and authentication.
  • E-learning: Allows learning at your own convenience, often requiring a network.

3. SDLC (Software Development Life Cycle)

  • Models include Waterfall, Iterative, and Spiral.
  • PERT Chart: Shows task dependencies. It does NOT show a calendar view of which tasks are happening on a particular date (Gantt charts do that).
